# Simple Store Website

A simple e-commerce website created as a team project using HTML and CSS.

## Project Description

This project is a basic online store website where users can view products and navigate through different pages.

## Features

- Homepage with featured products
- Product page
- Contact page
- Responsive design
- Simple and user-friendly navigation

## Technologies Used

- HTML
- CSS
- Git
- GitHub

## Team Workflow

The project uses Git and GitHub for collaboration.

1. Create a feature branch
2. Develop the assigned feature
3. Commit the changes
4. Push the branch to GitHub
5. Create a Pull Request
6. Review and merge the changes into `main`

## Branches

- `main` - Stable version of the project
- `feature-homepage` - Homepage development
- `feature-products` - Product page development
- `feature-contact` - Contact page development
